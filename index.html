Acerca de este proyecto

Este proyecto muestra las rutas de red (traceroute) desde diferentes puntos del mundo hacia los principales servicios de internet. Cada mapa muestra:

  • Puntos de conexión: Las diferentes paradas (hops) en la ruta
  • Líneas de conexión: El camino que sigue la información
  • Información IP: Las direcciones IP de cada punto

Para ejecutar localmente: python -m http.server 8000 y acceder a http://localhost:8000/traza/
